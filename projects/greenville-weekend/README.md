# Greenville NC Weekend Itinerary Generator

A React + TypeScript web application for discovering and planning weekend activities within a 2-hour drive of Greenville, NC (February 27 – March 1, 2026).

## Features

### Output #1: Event Database
- **48 events** across **16 cities** within a 2-hour drive
- Full-text search across event names, descriptions, cities, and tags
- Filter by: Day (Fri/Sat/Sun), Category (13 types), Budget tier, Indoor/Outdoor, City, Dietary (Vegan/Vegetarian), Max distance
- Sort by: Day & Time, Distance, Price, City
- Per-event iCal (.ics) export for calendar apps
- Bulk iCal export for all filtered events
- Events grouped by day with weather forecasts

### Output #2: Curated Itineraries
- **6 hand-crafted day trip itineraries** with detailed schedules
- Morning / Afternoon / Evening time blocks
- Per-stop details: time, duration, price, location, notes, booking links
- Food stop summaries with vegan/vegetarian options highlighted
- Weather contingency plans (good weather vs. rain alternatives)
- Practical info: departure time, parking, driving route, tips
- iCal export for itinerary events

### Output #3: Interactive Map View
- Google Maps integration showing all events as colored markers
- Filter by day on the map
- Click markers to see event details and iCal export
- Legend with category color coding

## Tech Stack
- React 19 + TypeScript
- Tailwind CSS 4
- shadcn/ui components
- Google Maps JavaScript API (via Manus proxy)
- Wouter for routing
